# COVID data cleaning practice

Uses the supplied historical sample. Cumulative totals use the latest nonmissing observation per country and include observation dates. Vaccination differences and revision flags are calculated in date order. `python analyze.py --output analysis.json` reproduces the analysis. The sample does not represent current conditions.

Install `requirements.txt`. Fresh numeric results and the completed verification checks are included. Pictures, videos and credentials are omitted. Original laptop copies are preserved.
